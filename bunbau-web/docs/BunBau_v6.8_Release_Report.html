1. Executive Summary

Milestone v6.8 establishes clean contextual modal isolation between brokerage portfolio ingestion and tax return filing ingestion across the BunBau web application. In response to user feedback, having universal 3-way tabs (PDF Upload, Brokerage CSV Export, and Screenshots) visible simultaneously in both portfolio and tax workflows introduced user confusion regarding what file types belonged to which workspace.

With Milestone v6.8, UploadValidationModal strictly scopes its tab rendering and active state by context:

  • In Portfolio Ingestion (context === 'portfolio'), the [PDF Upload (Tax Returns)] tab is completely hidden. The user sees only [Brokerage CSV Export] and [Screenshots (Vision)].
  • In Tax Return Ingestion (context === 'tax'), the [Brokerage CSV Export] and [Screenshots (Vision)] tabs are completely hidden. The user sees only [PDF Upload (Tax Returns)].

2. Architectural Remediation & Workflow Partitioning

Portfolio Ingestion Workflow

Context: context === 'portfolio'

  • Visible Tabs: [Brokerage CSV Export] & [Screenshots (Vision)]
  • Hidden Tabs: [PDF Upload (Tax Returns)] is completely excluded from DOM.
  • Active Tab Initialization: Defaults strictly to 'csv' (or 'vision'), never 'pdf'.
  • Domain Safety: Eliminates cross-talk with tax returns while preserving the entire existing CSV/vision parser pipeline.

Tax Return Ingestion Workflow

Context: context === 'tax'

  • Visible Tabs: [PDF Upload (Tax Returns)]
  • Hidden Tabs: [Brokerage CSV Export] & [Screenshots (Vision)] are completely excluded from DOM.
  • Active Tab Initialization: Strictly locked to 'pdf'.
  • Safety Guarantees: Prevents users from mistakenly uploading portfolio transaction spreadsheets into 1040/540 tax workflows.
