Key Technical Accomplishments

1. Multi-File PDF Ingestion Pipeline with Unlimited Uptake

  • PDF File Uptake Fixed: Dropzones and file inputs in UploadValidationModal.tsx accept .pdf,application/pdf.
  • Zero Brokerage Interference: CSV statements and brokerage screenshots remain 100% untouched and routed to existing financial parsers.
  • Incremental History Retention: Uploading 6 years of returns retains them in Firestore. Uploading future returns (e.g. 2026) retains and correlates all past history automatically.

2. Granular Phased Tax Deletion with Strict Phrase Verification

  • All Tax History: Requires exact phrase: Delete all tax history.
  • Single Tax Year: Requires exact phrase: Delete <Year> tax history.
  • Multi-Year Range: Requires exact phrase: Delete from <FromYear> to <ToYear> history.
  • Absolute Portfolio Isolation: Portfolio account and snapshot deletions continue using independent phrases, eliminating cross-contamination.

3. Continuous Scroll Virtualized Document Viewer

  • Standardized Scale: Standard letter-size canvas (PAGE_HEIGHT_PX = 920) ensures mathematically exact bookmark offsets.
  • DOM Virtualization: Renders currentScrollPage ± 2 in full DOM; lightweight placeholders for remainder prevent memory bloat.
  • 100% Continuous Scroll: Free mousewheel/drag scrolling allowed at all times with real-time scroll spy tracking active pages and bookmarks.
  • Pulsing Highlight Ring: Deep-linking to lines/pages renders an emerald focus ring.
  • Canonical Accessibility Zoom Bar: Strictly adheres to standard order: [-] [100% (Reset)] [+].

4. 10-Year Longitudinal Scalability Engine

  • Sub-50ms Speed: Benchmarked at 2ms for 10 full tax years in automated unit tests.
  • Macro Trajectory Table: Tracks W-2 wages, AGI, federal tax, California tax, total combined tax, effective combined tax rate, and YoY AGI growth.
  • Cumulative Loss Shield Ledger: Tracks capital loss carryovers and suspended passive rental losses across filings.
  • Multi-Column SmartTable: Dynamic columns for each year with category filters, search input, and 1-click source PDF deep-links.
