1. Executive Summary

In BunBau, brokerage account intelligence adheres to a clean separation of concerns:

  • Demo Mode: When a user logs in and has uploaded no statements (accounts.length === 0), the app activates Demo Mode, displays a prominent blue alert banner, and presents synthetic seed accounts.
  • Live Mode: Once the user uploads a verified statement, the app dynamically transitions to Live Mode, shows the green verified badge, and saves accounts in Firestore under users/{uid}/accounts.

Milestone v6.42 applies this exact pattern to the Tax Expert module:

  • Zero Private Data in Build: Completely purges all personal tax data from the repository source code and build.
  • High-Fidelity Synthetic Mock Returns: Generates realistic mock returns for fictitious taxpayers (Alex & Jordan Taylor) with identical mathematical and financial planning capabilities.
  • Dynamic TaxContext: Implements a runtime React context that detects whether tax return PDFs have been uploaded at runtime by the user.
  • Dynamic UI Banners: Renders a blue notice banner in Demo Mode and an emerald notice in Live Mode.
