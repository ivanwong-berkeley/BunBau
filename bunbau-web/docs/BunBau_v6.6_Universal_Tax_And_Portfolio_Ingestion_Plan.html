1. User Feedback & Defect Analysis

Defect 1: Upload Panel Mismatch on Tax Expert (Screenshot 1)

The universal modal is titled "Portfolio Ingestion" and only contains two tabs: [Brokerage CSV Export] and [Screenshots (Vision)]. Dragging in tax return PDFs placed them into the CSV queue, labeled them as CSV, and showed "Parsed Holdings (0 positions)". There is no dedicated PDF tab and no context-awareness.

Defect 2: Tax Ingestion Modal Rigidly Restricted to PDFs Only (Screenshot 2)

The modal opened from the tax banner only accepted .pdf files and rejected CSV or screenshot files. Users with 1099 CSVs, Schedule D trading exports, or scanned W-2/1040 screenshots could not ingest them.

3. Detailed Implementation Steps

Step 1: Mandatory Version Tracking & Version Guard

  • Update package.json → "2.7.8".
  • Update AboutModal.tsx → 2.7.8 & Build 123 & v2.9.1 Universal Multi-Modal Tax & Portfolio Ingestion Architecture (PDF, CSV, Vision).
  • Update page.tsx → v2.7.8 (Build 123).
  • Update version unit tests to enforce new version manifest.

Step 2: Smart Branching & Dedicated PDF Tab in UploadValidationModal.tsx

  • Add 3 Autonomous Tabs: [📄 PDF Upload (Tax Returns)], [📊 Brokerage CSV Export], and [📸 Screenshots (Vision)].
  • Context-Aware Initialization: When opened from the Tax Expert page (context="tax"), defaults to the PDF Upload tab and titles the modal "Tax & Portfolio Ingestion".
  • Strict Per-Tab File Type Enforcement:
    • CSV Tab: Rejects .pdf files with friendly guidance to switch to the PDF tab. Strictly accepts .csv.
    • PDF Tab: Strictly accepts .pdf tax returns.
    • Vision Tab: Strictly accepts images (.png, .jpg, .webp).
  • Tax Inspection Right Panel: In PDF mode, replaces "Parsed Holdings (0 positions)" with a dedicated Parsed Tax Filings Overview (Tax Year, Inferred Status, Detected Schedules, Total Pages).
  • Verification Action: "Verify & Ingest Tax Filings" calls importTaxReturnsBatch from TaxContext.

Step 3: Universal Multi-Modal Ingestion in TaxMultiUploaderModal.tsx

  • Accept All 3 File Types: Accepts PDFs (Form 1040/540/Schedules), CSVs (1099/Schedule D exports), and Scans/Images (W-2 scans, 1040 mobile photos).
  • Format Tabs: [📄 Tax Return PDFs], [📊 Tax CSV Exports], [📸 Tax Scans & Screenshots].
  • Multi-Format Format Badges: Staged files render clear badges: [PDF] (purple), [CSV] (blue), [IMG] (amber).
  • Multi-Format Staged Summary: Displays summary e.g. "4 PDFs, 1 CSV, 1 Scan Staged".

Step 4: Topbar Integration in page.tsx

  • Topbar "Upload Data" button passes context="tax" and initialTab="pdf" when the user is on the Tax Expert tab (activeTab === 'tax').

Step 5: Full Regression Testing & Production Build

  • Automated unit test: tests/unit/tax/universal_upload_modal.test.ts verifying context-aware defaults, file type enforcement, and multi-format tags.
  • Verify npm test across all 98+ test files.
  • Verify npm run build compiles 16/16 routes cleanly.
