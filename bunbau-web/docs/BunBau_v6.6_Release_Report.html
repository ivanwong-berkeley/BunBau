1. Executive Summary & Problem Resolution

Milestone v6.6 resolves the critical UX and architectural mismatches on the Tax Expert page by delivering a smart, context-aware upload engine across both primary ingestion entry points:

  • Upload Panel Mismatch Resolved (UploadValidationModal.tsx): Context awareness (context="tax") dynamically brands the modal as "Tax Return & Portfolio Ingestion" and introduces a 3-way top tab ribbon with a dedicated [📄 PDF Upload (Tax Returns)] tab set as the default on the Tax Expert page.
  • Strict Per-Tab File Type Enforcement: CSV file inputs now strictly accept .csv, .tsv, .ofx, .xlsx, .xls. Dropping a PDF into the CSV tab instantly warns the user with a redirect notice: "Tax return PDF detected! Switch to the 'PDF Upload' tab to ingest Form 1040/540 returns." Tax return PDFs are never mislabeled as CSVs or sent to an empty holdings table.
  • Parsed Tax Filings Overview: When activeTab === 'pdf', the right panel replaces empty brokerage holdings with a rich Tax Filings Overview featuring multi-year summaries, in-memory SSN masking confirmation, and an instant Verify & Ingest Tax Filings button.
  • Universal Multi-Modal Tax Uploader (TaxMultiUploaderModal.tsx): Accepts PDF returns, 1099/Schedule D CSVs, and W-2/1099 image scans with format filters ([All], [PDFs], [CSVs], [Scans]) and badges (PDF, CSV, IMG).
