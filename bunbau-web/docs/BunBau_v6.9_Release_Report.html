1. Executive Summary

Milestone v6.9 delivers a comprehensive UX and architectural upgrade across BunBau's Tax Return Ingestion and Multi-Year Audit systems. Addressing detailed production feedback, v6.9 introduces:

  • Interactive Green Monospace Terminal Stream & Staged Verification Workflow: A two-phase ingestion pipeline featuring pre-upload PDF previewing, a live green monospace extraction terminal, a parsed filings overview table with granular row and bulk checkboxes, dynamic button state reflecting verified count, and a final confirmation modal before database/storage persistence.
  • Dual-Entity Name Parsing & Spousal Isolation: Accurate joint return (MFJ) parsing isolating Harmony (Primary Filer) and Ivan (Spouse). Eradicates generic "Spouse" labels and removes compound "Harmony & Ivan" strings from individual taxpayer cards and lifecycle milestones.
  • Multi-Year Audit Deep Link Precision: California State Tax bookmarks now pinpoint California Form 540 Line 48 (Page 37 for 2024 / Page 35 for 2025), replacing erroneous offsets to Schedule E Part II.
  • Advanced PDF Viewer Player UX & Detach Option: A full-featured PDF workstation featuring a contained 800px viewport with in-viewer scrolling, Table of Contents (TOC) sidebar open by default on the left, keyword search, jump-to-page input (Page X of Y), canonical accessibility zoom controls, Print, Download, Document Info metadata modal, and a dedicated Detach / Re-attach workstation capability.

2. Key Deliverables & Remediation

2.1 Staged Ingestion & Green Monospace Terminal Workflow

The tax return ingestion workflow in UploadValidationModal.tsx was completely rebuilt to follow a staged, verifiable pipeline:

  • Pre-Upload PDF Preview: Users can inspect staged documents via data-testid="preview-staged-pdf-${idx}" prior to committing.
  • Confirm & Process Upload: An explicit button triggers document OCR and schedule parsing.
  • Streaming Green Terminal: Displays extraction progress logs inside bunbau_tax_ingestion_term.
  • Parsed Filings Overview Table: Only renders once extraction completes. Supports master "Verify All" and individual row verification checkboxes with status badges.
  • Verified Counter & Confirmation Modal: The ingest button indicates verified files and turns vibrant green, opening tax-ingest-confirm-modal before persistence.

2.2 Dual-Entity Name Parsing & Spousal Isolation

Joint return (MFJ) filers are accurately partitioned into Harmony (Primary) and Ivan (Spouse):

  • Ivan is never referred to with a generic "Spouse" header; cards render Spouse (Ivan).
  • Harmony is never conflated with the combined "Harmony & Ivan" string when rendering individual milestones or healthcare plans.

2.3 Multi-Year Audit Deep Link Precision

California State Tax line item deep links in longitudinalEngine.ts now accurately target California Form 540 Line 48 (Page 37 in 2024, Page 35 in 2025) rather than Schedule E.

2.4 Advanced PDF Viewer Player UX with Detach Option

BunBauDocumentViewer.tsx provides a contained 800px viewport, collapsible TOC sidebar open on the left by default, keyword search, jump-to-page pagination, canonical accessibility zoom controls, Print, Download, Info metadata modal, and a dedicated full-screen "Detach" workstation view.
